# AI Bubble — VO + Visual Script

·

## Style guide

Every voice-over line gets its own shot: a new picture or a clear change every 2–3 seconds, about 160 shots for ~12 minutes.

- 2D cartoon like the reference. Bold black outlines, flat colours, soft shadows, slightly muted backgrounds (office grey-green, boardroom brown, night blue).
- round white heads with dot eyes and eyebrows that act. Suits with red ties for execs and investors, hoodies for founders and devs. Papa has a moustache and specs, Beta a hoodie. Real CEOs are drawn generic: Sam = young exec in a grey sweater, Jensen = black leather jacket. No real faces.
- real logos allowed (Suraj's call): OpenAI, Google, Microsoft, Amazon, Meta, Nvidia, Instagram, Facebook.
- every dollar figure appears on screen as a big counter, chart or price tag, white with yellow highlight.
- NARRATOR = Suraj (cloned voice). Skits: Gaurav = young (Beta, engineer, founder, Sam), Amrut = older (Papa, Google boss, investor, board member), Devi = female (CEO, artist, Gemini).
- HF = Higgsfield 2D image, animated in code (camera move, blinks, mouth, props). CODE = drawn fully in code (charts, counters, text, icons).
