# FD se zyada — 3 instruments (16:9, ~35–40 s) — FINAL script (Suraj)

FD pe atke ho? Ye 3 instruments FD se zyada return de sakte hain.

1. Liquid fund
Pehla — Liquid fund. 6 se 7% tak, FD ke aas-paas.
Fark ye hai — FD todo toh penalty lagti hai, par isme koi penalty nahi.

2. Bonds
Doosra — Bonds. AAA rated bonds 7 se 8% dete hain, aur ye sabse safe maane jaate hain.
9 se 11% wale bonds bhi hain — par unme risk thoda zyada hai.

3. REITs
Teesra — REITs. Bade office buildings ka kiraya, seedha aapko.
Around 6–7% payout, upar se property ki growth. Ek unit kuch sau rupaye mein.
Matlab rental property — wo bhi saste mein.
