# Room in 3D with Claude (Hinglish reel) - FINAL script (25 Nov 2026)
Inspired by @tunestechtips "Comment ROOM" reel (own desi version).

[0-3] HOOK  VO: Ghar design karna hai? Architect ko lakhs dene se pehle... ye free mein try karo.
  SCREEN: "₹2,00,000" architect bill crossed out -> 3D room pops. Text "FREE mein?"
[3-7] VO: Bas apne room ki teen photo Claude ko bhejo... aur ye tumhara poora room 3D mein bana dega.
  SCREEN: 3 photos fan out (1,2,3) -> whoosh into 3D dollhouse.
[7-12] VO: Measuring tape? No need. Darwaza dekh ke ye size ka andaza laga leta hai.

  SCREEN: ✅ Deewar ❌ Darwaza takrayega ✅ Chalne ki jagah
[22-26] VO: Room ka colour bhi try karo. Sage green wala aesthetic? Ya mummy ka favourite peach?
[26-29] VO: 2-3 layout bhi suggest karta hai. Aur jo size guess kiya, wo bhi batata hai.
[29-33] VO: Comment karo "ROOM", main setup aur teen prompts bhej dunga.

## Decisions
- Room: sample middle-class Indian bedroom (double bed, almirah, study table, fan, switchboard, curtain window); 3 photos via Higgsfield (show price first).
- Genuine demo: actually build the 3D room tool from those photos (browser, drag/rotate, fit check, wall colours, layouts, size table) and record it.
- Style: screen-demo like reference (dark bg, browser frame, green highlight boxes); captions like reference (white, key word in green box, word-by-word).
- Voice: ElevenLabs harry potter, Eleven v4, 1.15x.
- CTA kit: PDF guide + 3 prompts (Hinglish), delivered via SuperProfile auto-DM for "ROOM".
- Cover: GPT prompt only. Platforms/music: decide later. Honesty: sizes are estimates ("andaza"), not an architect replacement.
