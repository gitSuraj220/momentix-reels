3 photo → tumhara room 3D mein

Claude se apna room 3D dollhouse ki tarah banao, furniture ghumao, sofa fit check karo, deewar ka colour try karo. Setup + 3 ready prompts, Hinglish mein.

STEP 1Kya chahiye

  • Claude (claude.ai, web ya app). Free plan pe bhi try kar sakte ho; Pro mein limits zyada milti hain.
  • Apne room ki 3 photos phone se.
  • Laptop/PC ka browser, 3D room kholne ke liye (phone pe bhi khul jaata hai).

STEP 2Photos kaise lo (sabse important)

  1. Photo 1: darwaze se, poora room dikhe (corner se khade hoke).
  2. Photo 2: ulti taraf se, darwaza saaf dikhe. Claude isi se size ka andaza lagata hai (normal darwaza 7 ft hota hai).
  3. Photo 3: khidki wali deewar, table/almirah ke saath.
Tips: din ki roshni mein lo, phone seedha pakdo (tilt mat karo), wide mode (0.5x) mat use karo, floor thoda dikhna chahiye.

STEP 3Prompts use karo

Agle page pe 3 prompts hain. Pehla prompt photos ke saath bhejo. Claude ek HTML file banayega. Use download karke browser mein kholo (ya claude.ai pe preview mein dekho).

Dhyan rahe: sizes andaza hain, exact measurement nahi. Sofa/almirah kharidne se pehle measuring tape se ek baar confirm kar lena. Construction ya structural kaam ke liye architect/engineer se hi baat karo.

PROMPT 1Room ko 3D mein banao

Main apne room ki 3 photos bhej raha hoon. Inse mera room ek 3D dollhouse ki tarah banao, ek single HTML file mein (three.js use karo). 1. Photos dhyan se dekho. Darwaze ko 7 ft maan ke (ya koi aur cheez jiska size pakka ho) deewar, ceiling, khidki aur furniture ke size ka andaza lagao. 2. Room ko isometric view mein dikhao: 2 deewarein poori, baaki 2 neechi (cutaway), floor pe tiles/flooring jaisa photo mein hai. 3. Furniture (bed, almirah, table, chair, etc.) wahi rakho jo photo mein hai, sahi jagah pe, simple 3D shapes aur sahi colours mein. 4. Har furniture ko mouse se drag kar sakun, aur R dabane pe 90° ghoom jaaye. 5. Darwaze ka khulne ka area (door swing) floor pe dikhao. 6. Side mein ek table do: har size jo tumne andaza lagaya, aur har ek ke saath likho "pakka" ya "guess".

PROMPT 2Fit check (sofa, almirah, bed)

Is room mein ek [7 ft x 3 ft] ka sofa add karo, jahan tumhe sabse sahi lage. Phir check karo aur saaf batao: ✓/✕ Deewar ke andar aata hai? ✓/✕ Darwaza khulte waqt takrayega? ✓/✕ Chalne ki jagah kam se kam 2 ft bachti hai? Agar koi ✕ hai, toh sofa ko kahan/kitna khiskaun ki sab ✓ ho jaaye, wo bhi batao aur 3D mein dikhao.

PROMPT 3Colour + layout makeover

Room mein neeche ek colour bar add karo: White, Sage green, Peach, Sky blue. Click karne pe deewaron ka colour badal jaaye. Phir mere room ke liye 3 alag layout suggest karo (A, B, C) aur buttons do jinse furniture animate hoke naye layout mein chala jaaye. Har layout ke saath 1 line mein likho ki ye kyun achha hai (zyada jagah, khidki ki roshni, etc.).
Kuch galat lage toh seedha bolo: "almirah left wali deewar pe hai", "bed 6 ft ka hai". Claude update kar dega.
