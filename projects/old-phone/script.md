# Old phone → desk panel (PhoneBox) — draft v1, 20 Nov 2026

Tool: PhoneBox by ersinkoc — https://github.com/ersinkoc/phonebox (MIT, free, no account, 3.9k stars).
Checked on the README (20 Nov 2026): 124 widgets, 30 templates; Windows / macOS / Linux; Android 5+ (6+ recommended), no iPhone;
USB (ADB debugging) or paired Wi-Fi; Claude/Codex quotas + reset times; Claude Code sessions; opt-in Claude Code
permission prompts answered Allow/Deny on the phone; media controls; shortcuts/macros; clocks, calendars, pomodoro timers.
Not stated in README, so not claimed: "phone buzzes when Claude finishes", "kills the slow app in one tap", night clock mode.
Caveat: Windows agent is unsigned for now, so SmartScreen/antivirus may warn.

## Script (Hinglish, ~30 s)
1. Purana Android phone becho mat. 🛑 Pehle computer se jodo.
2. Claude ko ek GitHub link do, bolo "set up kar do", phone USB se lagao. Bas.
3. Ab ye ban gaya tumhara desk panel — shortcut buttons, focus timer, calendar.
4. Gaana chal raha hai? Skip aur volume yahin se.
5. Claude Code permission maang raha hai? Phone pe "Allow" dabao, kaam chalta rahega.
6. Claude ka kitna limit bacha, kab reset hoga — sab live.
7. 124 widgets, 30 ready-made pages. Free aur open source.
8. Jo phone drawer mein pada tha… ab desk ka main character hai. 😎
