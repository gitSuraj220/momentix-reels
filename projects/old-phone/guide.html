WHAT YOU NEEDBefore you start

  • An old Android phone (Android 6 or newer recommended; iPhone is not supported)
  • A USB data cable (some charging-only cables won't work)
  • A Windows 10/11, Mac or Linux computer
  • Claude with access to your computer, for example Claude Code or the Claude desktop app

THE TOOLPhoneBox: free and open source

PhoneBox is a free, open-source project on GitHub (MIT license). No account and no cloud service needed.

https://github.com/ersinkoc/phonebox

STEP BY STEPSetup in 5 steps

1
Turn on USB debugging on the phone. Settings → About phone → tap Build number 7 times (this unlocks Developer options). Then Settings → Developer options → turn on USB debugging. Menu names can differ a little by brand.
2
Plug the phone into your computer with the data cable. When the phone asks "Allow USB debugging?", tap Allow (only for your own computer).
3
Open Claude and paste the prompt from the next page. Claude reads the project first, tells you what it will install, and waits for your OK.
4
Let Claude install it. It runs PhoneBox's official setup for your computer and installs the PhoneBox app on your phone over USB.
5
Pick your layout. Settings open at http://127.0.0.1:8765 on your computer. Choose one of the ready-made pages or drag widgets in yourself.

COPY-PASTEThe prompt for Claude

PASTE THIS INTO CLAUDE
I want to turn my old Android phone into a desk panel using PhoneBox: https://github.com/ersinkoc/phonebox

1. First read the project's README and its setup script, and tell me in simple words what will be installed on my computer and my phone. Wait for my OK.
2. Then run PhoneBox's official install command for my operating system.
3. My phone is connected by USB with USB debugging turned on. Install the PhoneBox phone app on it and check that the phone shows the panel.
4. Open the settings page (http://127.0.0.1:8765) and set up a starter page with: shortcut buttons, a focus timer, my calendar, music controls (play, skip, volume) and my Claude usage limits with reset time.
5. Turn on the Claude Code permission prompts so I can tap Allow or Deny on the phone (see docs/GUIDE.md in the project).

Explain each step in simple language, and ask me before changing any important setting.
Good to know
  • On Windows, the antivirus or SmartScreen may show a warning because the PhoneBox app is not signed yet. That is expected for this project; only continue if you are comfortable.
  • Phone not detected? Try another cable or USB port, unlock the phone, and accept the "Allow USB debugging" prompt.
  • Prefer no cable? PhoneBox can also pair over Wi-Fi with a QR code (see the project's setup guide).
  • Keep the phone on a stand and plugged in, so it stays charged while it works as a panel.
