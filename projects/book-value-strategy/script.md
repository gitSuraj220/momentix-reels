[1:15 STEP 1: BOOK VALUE]
Step one. Main sirf wo companies dekhta hoon jo apni book value ke paas ya usse neeche trade kar rahi hain.
Book value simple bhasha mein: company aaj apna saara saamaan bech de, saara karz chuka de, toh jo paisa bachega, wahi book value hai. Usko total shares se divide karo, mil gayi book value per share.
Ab socho. Share ka price book value se kam hai, matlab market company ko uske asli maal se bhi sasta bech raha hai. Literally sale lagi hai.
(SCREEN: price bar vs book value bar, price below)

[3:45 STEP 4: ENTRY + EXIT]
Company mil gayi. Ab sabse bada sawaal: khareedna kab, aur bechna kab?

Bechne ke mere do simple rules hain:
Rule one: agar 6 mahine ke andar share book value tak pahunch gaya ya cross kar gaya, main profit le leta hoon. Seedha.
Rule two: agar 6 mahine mein book value tak nahi pahuncha, toh main hold karta hoon, aur tab bechta hoon jab price book value ka double ho jaaye.
