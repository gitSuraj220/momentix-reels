# Animation style recipes

`animation_styles_viashaan.txt` — "Animation styles you can build with Claude" by Shaan Johari (@viashaan), saved 31 Oct 2026 from his public Notion page for reference. Each card: palette (hex), fonts, layout, motion, "Never" list, and a paste-in prompt.

Best fits for Momentix finance reels:
* **Finance and data: Stat Chart** — dark background, one huge counting number, line chart that turns orange at the event (IPO listing pop, stock moves, results).
* **Explainers: Paper Desk** — documents on a green cutting mat, red marker circles, highlighter (DRHP, filings, bills, salary slips).
* **News and commentary: Headline Highlight** — news headline marked up by hand.
* **Stories: Timeline** — 3D floor timeline with milestone cards popping up (process steps, history).

Always apply the "stop it looking AI-made" lines: no neon glow, no particle sparkles, no crossfades (shape change or cut), one bounce moment only, no camera shake/lens flare, no glowing grid floors, no text in frame corners, nothing template-like.
